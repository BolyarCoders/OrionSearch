# Provisional research boundary

Status: **proposal for ORION-8 review**, not an agreed AI-team contract. On 2026-10-18 ORION-8 was still To Do in Jira, and both remote branches contained only contract/worker placeholders. This directory does not implement or replace the Python engine.

The .NET worker proposes `POST research` relative to its configured agent base address, authenticated with a configured bearer service credential. Request/response JSON uses `contractVersion: "orion.research.provisional.v1"` and must echo the backend-issued `researchRunId`. The API never calls this service during submission. Normal processing is disabled; using this proposal requires explicit `AllowProvisionalContract=true` in addition to endpoint/credential configuration.

The request snapshots the server-authorized archive topic, objective and settings at submission. `researchRunId` is the public logical run; queue job IDs and attempt generations stay private. No database credentials, user identities or queue payload internals cross this boundary. Treat the objective and archive text as research data, never as authority to change backend settings or choose service endpoints.

The result contains `queries`, `sources` and `findings`, each bounded to 256 entries and a total HTTP response bounded to 2 MiB by default. Unknown properties, unsupported versions, missing required fields and invalid references fail permanently. Optional properties may be omitted; nullable dates remain unknown rather than receiving invented timestamps. [request.json](request.json) and [result.json](result.json) illustrate field spelling and a discovery without a capture. [request.schema.json](request.schema.json) and [result.schema.json](result.schema.json) provide JSON Schema 2020-12 shapes; cross-reference, normalization, hash-basis and exact-text checks also run in the backend validator.

Source keys and finding keys are response-local strings (1–80 ASCII letters/digits/dot/underscore/hyphen), not database UUIDs. Every normalized canonical URL must be unique within an output. Publishers are optional, with actual names and DNS domains. Captures are optional: a discovery creates a document/link only. A capture requires a UTC fetch timestamp and meaningful extracted text, raw capture metadata, or both. Raw references use durable absolute `s3`, `gs`, `https` or `urn` identifiers without credentials; the agent must have preserved the actual bytes and calculated the supplied lowercase SHA-256 digest. The backend validates the reference/digest shape; storage existence and external byte integrity require the storage integration and are not claimed verified by this boundary.

Text hashing uses the existing NFC/LF/outer-trim normalization. Chunk offsets count **Unicode scalar values in normalized extracted text**, start inclusive/end exclusive. Indices must be unique and nonnegative. Supplied offsets must exactly reproduce chunk text; without offsets the chunk must be an exact substring. For a globally deduplicated version, the same chunk index must retain the same text and offsets. Agree a deterministic chunking strategy with ORION-8 before live processing.

Evidence references a source key with a capture, plus an optional chunk index from that capture. Quotes must be exact substrings of the referenced text/chunk. Raw-only evidence cannot supply an unverifiable text quote or chunk. The backend resolves all database IDs after insertion/upsert; an agent cannot cite an arbitrary pre-existing version from another archive. Findings are stored as `unverified` even when an agent supplies supporting evidence or confidence. Confidence is metadata, not proof.

Persistence is backend-owned and transactional, including queries, documents, versions, chunks, findings/evidence, run, attempt and job completion. Replaying a terminal attempt is a no-op. A crash before commit rolls everything back. Concurrent archive ingestion reuses global publishers/documents/versions and preserves first captured metadata; adding a previously absent raw reference also records its own digest. Archive associations remain separate. First known publication/publisher/title data is retained when already stored. No Python service may write this database independently.

Replace/adapt this explicit boundary when ORION-8 lands. Mocked tests are not live LangGraph verification.
